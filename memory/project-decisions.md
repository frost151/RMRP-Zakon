Решения (16.10.2026):
- Платформа: Electron (десктоп Windows).
- Название программы: «Протокол» (окно «Протокол», заставка «РМРП / Протокол», ярлык «Протокол РМРП», productName RMRP Protokol, установщик RMRP-Protokol-Setup-X.Y.Z.exe; appId и папка userData rmrp-zakon прежние). (16.10.2026)
- Данные: законы НЕ хранятся на диске — при каждом запуске вся база качается с forum.rmrp.ru параллельно (6 потоков, ~2–3 с), заставка держит планшет до полной загрузки и показывает «N из 31»; нет связи → «Нет связи с форумом» + кнопка «Повторить». Старый laws.json удаляется при запуске. Кнопка ↻ перекачивает базу в памяти. (16.10.2026)
- Оверлей поверх игры, горячая клавиша настраиваемая, по умолчанию F9.
- Фракция выбирается переключателем в шапке (без экрана первого запуска), есть вариант «Все».
- Фракции: ГИБДД, УВД, ФСБ, Адвокат, СК/Прокуратура (ФСИН пользователь в списке не назвал — убрана).
- Дизайн: как служебный планшет госструктур; на фоне — герб выбранной фракции.
- Первый приоритет: выбор фракции; дальше поиск/калькулятор.
- Калькулятор: клик по наказанию под статьёй → правая колонка «Дело», внизу итог по УК 30 (сумма ≤15 лет, арест→1 год), КоАП 4.5/4.7, ПК 12/13/17.
- Поиск: номера через пробел («63 64 77», «ук 37.1 коап 9.3»), Enter — добавить всё в дело.
- Таймер задержания (ПК 6, 9, 10.3, 14.2) с хоткеями: F10 старт/пауза, F11 адвокат (вызов→ответил→прибыл); чекбоксы госслужащий / неприкосновенность / предварительное 15 мин; мини-окно таймера поверх игры.
- Копирование дела — формат «63.3 УК РФ, 66 УК РФ, 8.1 КоАП» (без итога).
- Штрафы УК: в итоге второй вариант «с заменой срока на штраф» (ПК 13.2) + переключатель «УК: Срок/Штраф».
- Кнопка «Отказался от уплаты штрафа»: КоАП с арестом → арест (4.6.1); УК → срок (ПК 13.2); только штраф (почти вся глава IX/ПДД) → авто-добавление ст. 67 УК по сумме (<30к 67.1, <50к 67.2, ≥50к 67.3). «штраф или лишение прав» — альтернатива, не добавка.
- У адвоката нет вкладки «Задержание» и хоткеев F10/F11 (по полю tools в laws-meta.js).
- Автопродолжение таймера после прибытия/неответа адвоката или представителей (снимает и ручную паузу).
- Звуки таймера: start/pause/resume/stop/warn/expired (сирена), синтез WebAudio в app.js SOUNDS.
- Колонку «Дело/Задержание» можно свернуть вправо в полосу (запоминается).
- Заставка как у Windows XP (чёрный экран, герб, «РМРП Закон», бегущие синие квадратики) при каждом запуске; выключателя нет и пропустить нельзя — на ней грузятся законы (минимум 2 с). Мелодия включения (своя, синтез). Звук смены фракции. (16.10.2026)
- Звуки: кнопки-динамика в шапке больше нет; в настройках раздел «Звуки» с тремя галочками — загрузка (мелодия), приложение (смена фракции), таймер задержания (settings.sounds {startup, ui, timer}; старый uiSound переносится). Галочка таймера скрыта у адвоката. (16.10.2026)
- Автор только на рамке планшета (гравировка «Артем Гольдрин · 541-657»), справа снизу на рамке — номер версии. На экране имени нет.
