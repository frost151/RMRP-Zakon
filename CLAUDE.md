# Протокол (РМРП)

Память проекта (цель, принятые решения, стиль работы с пользователем, особенности сборки) в репозиторий не кладётся. Она хранится в памяти Claude, а резервная копия лежит в папке `Протокол - память Claude` на рабочем столе пользователя. Если в памяти Claude ничего нет, попроси пользователя скопировать эту папку на компьютер и прочитай её: начни с `MEMORY.md`.

- Пути вида `C:\Users\SommuS\...` в памяти относятся к первому компьютеру. На другой машине сверь их с фактическим окружением.
- Когда сохраняешь новые решения в память, обновляй и папку `Протокол - память Claude` на рабочем столе. На GitHub память не заливай.
- При каждой новой функции или исправлении добавляй пункт в `src/renderer/changelog.js` (окно «Что нового»).

## Как запустить на новом компьютере

1. Установить Node.js, Git и GitHub CLI: `winget install OpenJS.NodeJS.LTS Git.Git GitHub.cli`
2. Войти в GitHub: `gh auth login`, затем `gh repo clone frost151/RMRP-Zakon`
3. В папке проекта: `npm install`. Если Electron не скачивается, поставь `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`.
4. Запуск: `npm start` (из VS Code сначала убрать переменную `ELECTRON_RUN_AS_NODE`). Установщик собирается через `powershell -ExecutionPolicy Bypass -File build\dist.ps1`.
